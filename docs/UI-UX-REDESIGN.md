# Local Camera UI/UX 개선 결과

검증일: 2026-10-25 (한국 시간)

## 분석 및 설계

기존 구성은 FastAPI + 서버 RTSP→MJPEG + 순수 HTML/JavaScript입니다. ONVIF 모듈은 존재하지만 웹 제어 API는 검증된 DVRIP를 사용합니다. 프레임워크나 상태 관리 의존성을 추가하지 않았습니다. 기존 오디오, 웹 로그인, 타임랩스, SD 녹화 API와 RTSP 변환 인자는 유지했습니다.

기존 UI의 연결 배지는 고정 문구였고, 영상 로딩·오류 표시와 수신 여부 구분이 부족했습니다. 브라우저에 따라 MJPEG의 `load` 이벤트가 스트림 종료 전 발생하지 않는 문제를 고려해야 했습니다. 프리셋 조회 API가 없으므로 “저장된 프리셋 없음”이라는 단정도 제거했습니다.

정보 구조:

```text
Desktop: 제품/장치 상태/설정 → 기존 3개 탭 → [넓은 영상 | 접을 수 있는 PTZ] → 상태
Tablet:  영상 중심 → 아래 PTZ (방향 패드와 속도·기능 설명을 두 열로 배치)
Mobile:  전체 폭 영상 → 툴바/상태 → 접을 수 있는 오디오 → PTZ → 기능 지원 안내
```

`AppShell`, `CameraHeader`, `ConnectionIndicator`는 HTML 시맨틱 구조와 디자인 토큰을 공유합니다. `CameraPlayer`, `StreamStatus`, `PlayerToolbar`, `PTZController`, `PTZDirectionalPad`, `CameraSettings`의 동작은 `live.js`의 책임별 블록으로 나눴습니다. 줌·프리셋 영역은 미지원 안내만 제공하며 API를 호출하지 않습니다. 기존 `audio.js`, `timelapse.js`, `sd.js`, `session.js`가 담당하는 기능은 유지했습니다.

## 영상 및 상태

- 기본 16:9, `object-fit: contain`. 전체화면에서도 프레임을 자르지 않습니다.
- 장치 연결과 영상 수신을 별도 상태로 관리합니다. 연결 중 / 수신 / 재연결 / 연결 해제 / 오류를 구분합니다.
- 영상의 실제 `naturalWidth` / `naturalHeight`만 표시합니다. 원본 센서 해상도, 실측 FPS, 지연, 확인하지 않은 코덱 수치를 만들지 않습니다. 전송 형식은 실제 MJPEG입니다.
- MJPEG 첫 프레임은 기존 1초 상태 조회 시 크기로 감지합니다. 정상 수신 중에는 상태 조회가 영상 URL을 교체하지 않습니다.
- 첫 프레임을 15초 동안 받지 못하면 기존 JPEG 스냅샷 미리보기로 전환합니다. 미리보기는 LIVE 배지를 숨기고 5초 갱신임을 표시합니다. 재연결 버튼으로 MJPEG를 다시 시도할 수 있습니다.
- 현재 표시 중인 프레임은 브라우저 Canvas로 JPEG 저장합니다. 추가 카메라 연결이나 별도 서버 저장을 만들지 않습니다.
- 전체화면 내부에 명시적인 종료 버튼을 제공합니다.
- 영상 읽기와 생성기 종료를 응답별 잠금으로 직렬화합니다. 검증 서버 종료에서 발견한 `generator already executing` 경합을 수정하고, 실제 작업 취소와 진행 중인 읽기가 겹치는 회귀 테스트를 추가했습니다.
- 화면 전환, 비가시 상태, 페이지 종료 시 영상 연결을 해제합니다. 보관함 화면에서는 실시간 연결 확인도 중단합니다.

## PTZ 안전 동작

- 기존 `/api/move`, `/api/stop` 계약, DVRIP 인증, 검증 프로필, 소켓 타임아웃(기본 3초, 기존 설정 범위 1~10초)을 유지합니다.
- 한 번 누를 때 이동 요청은 한 번만 전송합니다. 자동 반복 이동을 하지 않습니다. 클라이언트와 기존 서버 모두 2초 이동 제한을 둡니다.
- 해제 시 이동 응답을 기다리지 않고 STOP을 전송합니다. 이동 요청이 아직 처리 중이었다면 응답 완료 후에도 STOP을 다시 전송하여 순서 역전 가능성에 대응합니다.
- HTTP 요청은 6초 제한을 적용합니다. 실패한 STOP은 한 번만 추가 시도하고, 이동은 재시도하지 않습니다. STOP 전달에 실패하면 이동을 잠그고 정지 재시도를 안내합니다. 과거의 성공 상태로 잠금을 해제하지 않습니다.
- 서버가 정지 확인 실패를 보고하면 이동을 잠급니다. 성공한 수동 STOP과 장치의 정지 응답 증거를 확인한 뒤 잠금을 해제합니다.
- pointerup / pointercancel / lostpointercapture / 포커스 상실 / 브라우저 blur / 화면 숨김 / 페이지 종료 / 화면 전환 / PTZ 접기 / 네트워크 offline을 처리합니다.
- 방향키·Space·Enter는 PTZ 패드 내부에서만 처리합니다. Escape는 정지합니다. OS 키 반복은 추가 이동을 만들지 않습니다. 이동 상태 조회 때문에 현재 누른 버튼이 비활성화되어 조기에 포커스를 잃지 않도록 처리했습니다.
- 서버의 조기 해제 경로에서 주 연결 STOP 실패 후 감시 타이머가 취소되면, 독립 연결로 STOP을 추가 시도합니다. 실패 내역과 응답 증거는 기존 결과 구조에 보존합니다.

장치 자체의 이동 타임아웃은 확인되지 않았습니다. 서버의 2초 제한은 명령 실행과 STOP 시도를 제한하는 것이며, 모든 네트워크 경로가 끊긴 상황에서 물리적 정지를 보장하지는 못합니다. HTTP 202는 정지 요청 접수이며 모터 정지의 물리적 증거로 표시하지 않습니다.

## 제한 및 운영 적용

- 줌·홈·프리셋은 장치 지원과 API가 검증되지 않아 비활성입니다. ONVIF 백엔드를 임의로 교체하거나 지원한다고 표시하지 않았습니다.
- 실측 FPS·지연·프레임별 갱신 시각은 제공하지 않습니다. 브라우저 img 기반 MJPEG는 이미 표시된 프레임 이후의 조용한 정체를 완벽히 감지하지 못합니다.
- 모터를 실제로 움직이는 재검증과 물리적 버튼 해제 후 정지 확인은 이번 작업에서 수행하지 않았습니다. 입력·서버 안전 경로는 모의 장치로 검증했으며 기존 검증 프로필은 변경하지 않았습니다.
- 오디오·SD 녹화 기능은 기존 회귀 테스트로 확인했습니다. 실제 마이크 송출과 SD 파일 가져오기를 이번 브라우저 검증에서 실행하지는 않았습니다.
- 새 외부 호출이 없고 서버의 기존 로컬 통신 경로를 유지합니다. 공유기 방화벽 규칙 자체는 변경하거나 재검증하지 않았습니다.
- 운영 컨테이너 배포/재시작은 수행하지 않았습니다. 임시 검증 서버는 종료했습니다. 소스 실행은 기존 `serve` 프로세스 재시작으로, Docker 실행은 기존 환경 변수를 유지하여 이미지를 다시 빌드한 뒤 적용합니다.

## 모바일 최적화 및 Docker 적용 (후속 작업)

2026-10-25 사용자 요청으로 모바일 화면을 추가 최적화하고 실제 운영 웹 컨테이너에 적용했습니다. 앞선 “운영 배포 미수행”은 최초 UI 작업 시점의 기록이며, 이번 후속 작업에서 배포를 완료했습니다.

- 540px 이하에서는 영상 바로 아래에 PTZ를 배치하고 오디오는 그 다음으로 이동했습니다. 390×844에서 200px 방향 패드 전체가 초기 화면의 하단 탭 위에 표시되는 것을 확인했습니다.
- 실시간·타임랩스·SD 녹화 메뉴는 모바일 하단 탭으로 제공하며 하단 안전 영역만큼 여백을 확보합니다. 콘텐츠에도 탭 높이만큼 여백을 둡니다.
- 영상은 모바일 전체 폭으로 표시하고, 제목과 헤더 여백을 줄였습니다.
- 줌·홈·프리셋 지원 안내는 “추가 기능”을 펼쳐 확인합니다. 미확인 상태와 비활성 동작은 유지합니다.
- 가로 모드에서는 영상과 작은 PTZ 패널을 나란히 배치합니다. 입력 폰트는 모바일에서 16px로 설정해 iOS의 입력 시 자동 확대를 줄였습니다.
- 노치·홈 표시줄 안전 영역과 동적 화면 높이에 대응합니다. 실제 노치 기기에서의 검증은 수행하지 않았습니다.

### 모바일 전체화면 호환성 수정

기존 구현은 `requestFullscreen()` 미지원/거부 시 오류만 표시했습니다. 이제 클릭 즉시 `position:fixed`와 동적 뷰포트 높이로 영상 영역을 펼치고, 지원되는 경우에만 표준/WebKit 네이티브 전체화면을 추가 요청합니다. 네이티브 요청이 실패해도 확대 모드를 유지합니다. 미지원 기기의 브라우저 주소창·OS 상태 표시줄은 숨길 수 없습니다.

전체화면에서 닫기·듣기·말하기 버튼을 유지하고, 영상은 contain으로 표시합니다. 닫기/Escape/네이티브 전체화면 종료/화면 전환/탭 숨김 시 확장을 해제하고 스크롤과 포커스를 복구합니다. PTZ 입력은 전체화면 진입 시 해제하며, 방향키가 영역 밖에서 이동을 만들지 않는 기존 동작도 검증했습니다.

API 미지원·요청 거부·표준 API·WebKit 경로를 JS 하니스에서 검증했습니다. 임시 페이지에서 네이티브 요청을 끈 상태로 390×844 및 844×390 브라우저 화면 채움, 960×540 영상 표시, 회전 후 contain 유지, 닫기 후 body 스크롤 잠금 해제를 확인했습니다. 실제 iPhone 기기 검증은 수행하지 않았습니다. 전체 회귀 테스트 162개 통과.
